## Key Capabilities

Atlas-tech offers a suite of features designed to enhance AI memory management:

- **Persistent Storage**: Store and retrieve memory data with guaranteed durability across sessions.
- **Contextual Retrieval**: Access memories based on relevance and recency for optimal AI responses.
- **Scalable Architecture**: Handle millions of memory operations with enterprise-grade performance.
- **Secure Integration**: Implement robust authentication and encryption for sensitive memory data.

<Tabs>
  <Tab title="Python" icon="code">
    <Steps>
      <Step title="Install SDK" icon="download">
        Install the Atlas-tech Python SDK:
        ````bash
        pip install atlas-tech
        ````
      </Step>
      <Step title="Initialize Client" icon="settings">
        Create a client instance:
        ````python
        from atlas_tech import MemoryClient
        
        client = MemoryClient(api_key="your_api_key")
        ````
      </Step>
      <Step title="Store Memory" icon="save">
        Store a memory entry:
        ````python
        memory_id = client.store_memory(
            content="User prefers blue theme",
            user_id="user123",
            tags=["preference", "ui"]
        )
        ````
      </Step>
    </Steps>
  </Tab>
  <Tab title="JavaScript" icon="code">
    <Steps>
      <Step title="Install Package" icon="download">
        Install via npm:
        ````bash
        npm install atlas-tech-js
        ````
      </Step>
      <Step title="Initialize SDK" icon="settings">
        Set up the client:
        ````javascript
        const { MemoryClient } = require('atlas-tech-js');
        
        const client = new MemoryClient({
          apiKey: 'your_api_key'
        });
        ````
      </Step>
      <Step title="Retrieve Memories" icon="search">
        Query memories:
        ````javascript
        const memories = await client.queryMemories({
          userId: 'user123',
          tags: ['conversation'],
          limit: 10
        });
        ````
      </Step>
    </Steps>
  </Tab>
</Tabs>
