## Memory Clustering

Atlas-tech automatically clusters related memories to improve retrieval accuracy and provide contextual insights.

<CodeGroup tabs="Python,JavaScript">
  ```python
  # Enable clustering for a user
  client.enable_clustering(user_id="user123", options={
      "similarity_threshold": 0.8,
      "max_cluster_size": 50
  })
  
  # Query clustered memories
  clusters = client.query_clusters(user_id="user123", topic="shopping")
  ```
  ```javascript
  // Enable clustering
  await client.enableClustering('user123', {
    similarityThreshold: 0.8,
    maxClusterSize: 50
  });
  
  // Query clusters
  const clusters = await client.queryClusters('user123', 'shopping');
  ```
</CodeGroup>

## Custom Metadata

Extend memory entries with custom fields for advanced filtering and analytics:

<Tabs>
  <Tab title="Store with Metadata" icon="save">
    ````json
    {
      "content": "User purchased premium subscription",
      "user_id": "user456",
      "tags": ["purchase", "subscription"],
      "metadata": {
        "event_type": "ecommerce",
        "value": 99.99,
        "currency": "USD",
        "product_category": "software",
        "campaign_id": "summer2024"
      }
    }
    ````
  </Tab>
  <Tab title="Query by Metadata" icon="search">
    ````python
    # Filter by custom metadata fields
    memories = client.query_memories(
        user_id="user456",
        metadata_filters={
            "event_type": "ecommerce",
            "value": {"$gte": 50}
        }
    )
    ````
  </Tab>
</Tabs>

<Callout kind="info">
  Metadata fields support various data types including strings, numbers, booleans, and nested objects.
</Callout>
