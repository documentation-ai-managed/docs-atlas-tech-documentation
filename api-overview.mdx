## Authentication

All API requests require authentication using your API key:

<CodeGroup tabs="cURL,Python">
  ```bash
  curl -X GET \
    "https://api.atlas-tech.com/v1/memories" \
    -H "Authorization: Bearer YOUR_API_KEY" \
    -H "Content-Type: application/json"
  ```
  ```python
  import requests
  
  headers = {
      "Authorization": "Bearer YOUR_API_KEY",
      "Content-Type": "application/json"
  }
  response = requests.get("https://api.atlas-tech.com/v1/memories", headers=headers)
  ```
</CodeGroup>

<Callout kind="info">
  API keys should be kept secure and rotated regularly for security.
</Callout>

## Response Format

All API responses follow a consistent JSON structure:

<Response tabs="Success,Error" show-lines="false">
  ```json
  {
    "success": true,
    "data": {
      "id": "mem_abc123",
      "content": "User prefers dark mode",
      "user_id": "user789",
      "tags": ["preference", "ui"],
      "created_at": "2024-01-15T10:30:00Z",
      "updated_at": "2024-01-15T10:30:00Z"
    },
    "metadata": {
      "request_id": "req_xyz456",
      "processing_time_ms": 45
    }
  }
  ```
  ```json
  {
    "success": false,
    "error": {
      "code": "INVALID_API_KEY",
      "message": "The provided API key is invalid",
      "details": {
        "field": "authorization"
      }
    },
    "metadata": {
      "request_id": "req_xyz456",
      "processing_time_ms": 12
    }
  }
  ```
</Response>

<Expandable title="Error Codes" default-open="false">
  - `INVALID_API_KEY`: Authentication failed
  - `RATE_LIMIT_EXCEEDED`: Too many requests
  - `MEMORY_NOT_FOUND`: Specified memory does not exist
  - `VALIDATION_ERROR`: Invalid request parameters
  - `SERVER_ERROR`: Internal server error
</Expandable>

<ExpandableGroup>
  <Expandable title="Rate Limiting" default-open="true">
    API requests are rate limited based on your plan. Check response headers for limit information.
  </Expandable>
  <Expandable title="Pagination" default-open="false">
    List endpoints support pagination with `limit` and `cursor` parameters for large result sets.
  </Expandable>
</ExpandableGroup>
